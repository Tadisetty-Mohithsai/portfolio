# Tadisetty Mohith Sai — Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in your browser.

No build tools or package installation are required. The page uses Google Fonts and Lucide icons from CDNs, so those decorative assets need an internet connection.

## Files
- `index.html` — page structure and content
- `style.css` — responsive dark theme and animations
- `script.js` — mobile navigation, current year, and scroll reveal

## Before publishing
Review the phone number, email address, coding-profile URLs, and project repository links to make sure they are current. You can publish this folder with GitHub Pages.
